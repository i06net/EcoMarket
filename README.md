## Descripción

EcoMarket es una plataforma orientada a conectar consumidores con comercios locales sostenibles, permitiendo encontrar productos y establecimientos cercanos según diferentes criterios de búsqueda y preferencias.

El presente repositorio contiene el backend de EcoMarket, desarrollado como una API RESTful para gestionar usuarios, comercios, productos, búsquedas, recomendaciones y funcionalidades relacionadas con el consumo sostenible.
